============================================================
 راهنمای اضطراری بازیابی پروژه «دوز ایرانی» (Dooz)
============================================================

اگر این ماشین پاک شد، با این راهنما همه‌چیز را بازمی‌گردانی.

--------------------------------------------
۱) کلید امضای release (مهم‌ترین چیز)
--------------------------------------------
کلید داخل گیت‌هاب است (آرشیو رمزگذاری‌شده):
  backup/dooz-keystore-2026-10-29.7z

در هر ماشین تازه:

  git clone https://github.com/salehkheiri1995-png/doozirani.git
  cd doozirani
  DOOZ_KEY_PASSPHRASE='<رمز آرشیو از ایمیل>' ./scripts/bootstrap.sh

bootstrap.sh خودش آرشیو را باز می‌کند، مسیر را اصلاح می‌کند و
اثرانگشت SHA-1 را بررسی می‌کند (باید BE:09:01:79:...:0E:BB باشد).

رمز آرشیو فقط در ایمیل/مدیر گذرواژه است؛ هرگز در گیت یا فایل نگذار.

--------------------------------------------
۲) ساخت APK امضاشده
--------------------------------------------
روی ویندوز:
  pwsh -File scripts\release.ps1
روی لینوکس:
  ./scripts/release.sh
خروجی: dooz-release.apk (نسخه ۱۳ / ۱.۵.۶)

بررسی امضا قبل از آپلود:
  C:\Android\android-sdk\build-tools\<version>\apksigner.bat verify --print-certs dooz-release.apk
  # باید SHA-1 = BE:09:01:79:7A:E7:B0:52:1B:C1:49:AE:34:F5:F2:D8:A5:B0:0E:BB

--------------------------------------------
۳) آپلود در کافه‌بازار
--------------------------------------------
نسخه فعلی بازار با کلید قدیمی امضا شده؛ اول تیکت تغییر کلید
(BAZAAR_SUPPORT_TICKET.txt) را برای پشتیبانی بفرست. بعد از تأیید،
dooz-release.apk را آپلود کن. نسخه بعدی باید versionCode بزرگ‌تر از ۱۳ داشته باشد.

--------------------------------------------
۴) اگر این شاخه هنوز push نشده
--------------------------------------------
کامیت‌های ما الان فقط روی همین ماشین هستند. هرچه زودتر:
  git push -u origin fix/multiplayer-economy-online
اگر دسترسی نداری، از مالک ریپو بخواه یک Pull Request بگیرد.

--------------------------------------------
۵) محتوای این کیت
--------------------------------------------
- dooz-release.apk            (APK نهایی امضاشده، نسخه ۱۳)
- dooz-keystore-2026-10-29.7z (کلید رمزگذاری‌شده — همان که در گیت هم هست)
- scripts/                     (بازیابی و ساخت خودکار)
- این فایل
